# AI Assistance and Research Transparency

This repository was developed with assistance from OpenAI's ChatGPT.

ChatGPT was used as:
- a programming assistant;
- a workflow-refactoring assistant;
- a documentation assistant;
- a brainstorming tool for exploratory analysis design.

Human-authored contributions include:
- research conception;
- methodological direction;
- interpretation of results;
- analytical decisions;
- code validation and testing;
- final manuscript/proposal writing decisions.

No outputs generated by ChatGPT were accepted without review and modification.
